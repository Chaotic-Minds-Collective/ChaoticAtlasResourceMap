# CMG ATLAS Resource Map

The **Chaotic Minds Gaming (CMG) ATLAS Resource Map** is an interactive map for exploring ATLAS islands, resources, and travel information.

This repository contains the static map application and its supporting map assets. It is part of the CMG ATLAS tool ecosystem.

## Contents

- `example.html` — map application entry page.
- `atlasmap.js` and `style.css` — map client and presentation.
- `atlasIcons/`, `icons/`, `images/`, `json/`, and `site/` — map assets and data.

The upstream Leaflet license and third-party attributions are preserved in the repository.
